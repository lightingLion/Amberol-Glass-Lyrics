# Amberol Glass Lyrics 桌面应用使用说明

## 安装状态

应用已安装到本机，可在 GNOME 应用菜单搜索 **Amberol Glass Lyrics**。

也可从终端启动：

```bash
amberol-glass-lyrics
```

独立应用 ID：`io.github.amberolglass.Lyrics`。

## 歌词使用

1. 把 `.lrc` 歌词放在歌曲同一目录。
2. 歌词文件名需要与歌曲文件名相同。

示例：

```text
Glass in the Rain.flac
Glass in the Rain.lrc
```

支持标准时间标签、多个时间标签和 `[offset:+/-毫秒]`：

```lrc
[offset:-200]
[00:01.20]第一句歌词
[00:05.40]第二句歌词
```

同名 `.txt` 可作为纯文本歌词后备。

## 操作

- 歌词卡片固定显示在播放界面右侧，不再使用展开、关闭或弹出动作。
- 播放队列可以独立打开，不改变歌词卡片状态。

## 自适应窗口与歌词卡片

窗口使用 `GtkOverlay + GtkRevealer + AdwBreakpoint` 实现固定歌词卡片：

- 歌词卡片始终位于播放界面右侧上层，不再改变顶层窗口宽度；
- 默认窗口为 1170sp，歌词卡片及间距占 390sp，播放器与歌词形成约 2:1 的视觉比例；
- 1000sp 以上播放器平滑让出 390sp，避免核心控制被歌词遮挡；
- 1000sp 以下收起 270sp 动态避让，但保留 120sp 基础避让，减少歌词对封面和播放控制的视觉影响；
- 歌词卡片本身始终保持 360sp 和原位置；
- 卡片外没有点击层、白色底层、模糊层或半透明遮罩；
- 播放器主体放入可滚动容器，短窗口可以继续缩小而不会强制保持原高度；
- 顶层只设置默认尺寸，窗口实际最小尺寸由 GTK 内容测量决定；
- 用户调整窗口时始终沿用 Amberol 原有播放布局基础。

## Gray-Scott 图灵歌词

歌词卡片采用连续的 Gray-Scott U/V 化学场：

- 参考 `ph-200711/Turing-Patterns-Music-Video-Generator` 的细密迷宫与 hazy void 配方；
- 每首音频生成自己的稳定随机种子，小圆点经过 3600 次真实反应扩散后铺满画布；
- 初始化期间播放器保持暂停，收到 `pattern-ready` 后从歌曲开头继续；
- Pango/Cairo 只产生字形覆盖率，歌词通过 `U→1、V→0` 的短时化学约束成为纹路空腔；
- 约束在 0.30 秒内建立，并保持到当前句演唱结束；换句后旧字腔才解除约束并由 Gray-Scott 从边缘自然回填；
- 显示 Shader 只按 Chemical V 浓度和梯度着色；暗部、中间色和高光色由专辑封面的多种提取色混合生成；字形外缘通过一条约 1 texel 的 Chemical V 高浓度细环形成白色描边；
- GStreamer 以 20 ms 精度驱动 LRC，换句严格服从毫秒时间戳；
- 模拟纹理为 `768×1024`，当前 `F=.0480`、`K=.0615`，GTK 30 FPS 下每帧执行 48 次模拟；歌词字号按字符数量分级，并继续以 2pt 步进缩小，直到实际 Pango 布局进入安全区域；
- 整个过程没有可见 GtkLabel、黑字贴图、隐藏旧纹理恢复或普通淡入淡出。

算法和状态机记录见 `docs/图灵歌词原型.md` 与 `docs/反应扩散参考实现.md`。

## 当前版本功能

- 保留 Amberol 本地播放、播放队列、波形、封面取色、MPRIS 和 GStreamer 后端。
- 原生 Rust + GTK4 + libadwaita 实现，不使用 WebView。
- 毛玻璃歌词卡片、透明卡片外区域和 GPU 图灵纹斑手书歌词背景。
- 同名 LRC 自动加载与逐句同步。
- 同名 TXT 后备。
- 歌词和队列互斥。
- 独立桌面入口、应用 ID、资源目录、翻译域和可执行文件名。

## 版本管理

源码使用 Git 管理；本次桌面应用与反应扩散背景作为独立里程碑提交。后续修改应先检查 `git status`，完成编译和测试后再提交。
