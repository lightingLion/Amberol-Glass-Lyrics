# Amberol Glass Lyrics 桌面应用使用说明

## 安装状态

应用已安装到本机，可在 GNOME 应用菜单搜索 **Amberol Glass Lyrics**。

也可从终端启动：

```bash
amberol-glass-lyrics
```

独立应用 ID：`io.github.amberolglass.Lyrics`。

## 歌词使用

1. 把 `.lrc` 歌词放在歌曲同一目录。
2. 歌词文件名需要与歌曲文件名相同。

示例：

```text
Glass in the Rain.flac
Glass in the Rain.lrc
```

支持标准时间标签、多个时间标签和 `[offset:+/-毫秒]`：

```lrc
[offset:-200]
[00:01.20]第一句歌词
[00:05.40]第二句歌词
```

同名 `.txt` 可作为纯文本歌词后备。

## 操作

- 右上角歌词按钮：展开或收起歌词卡片。
- `Ctrl+L`：切换歌词面板。
- `Esc`：关闭歌词面板。
- 点击左侧模糊区域：关闭歌词面板。
- 打开歌词时播放队列会自动收起；打开播放队列时歌词会自动收起。

## 窗口稳定性

歌词展开前会锁定左侧播放器的实际分配宽度，再请求顶层窗口扩展；歌词区域显示和窗口收缩也采用分阶段处理。因此专辑封面、波形、标题和播放控件不会在延伸瞬间重新排版或横向跳动。

## 图灵反应扩散歌词原型

歌词主体现在由 `GtkGLArea` 中的连续 Gray-Scott 系统生成，不再由可见 `GtkLabel` 叠加：

- Pango/Cairo 为每句真实歌词生成单通道字形遮罩，并选择受控候选位置；
- 遮罩注入 Chemical B，依次经历离散播种、纹路生长、稳定和换句侵蚀；
- 当前与上一句分别保留为 `textMask` / `previousTextMask`，旧句不会换句即删除；
- Display Shader 仅输出“化学浓度 × 字形约束 + 有机边缘发光 + 专辑配色”，不直接输出纯色遮罩；
- 空闲区域和换句期间共用同一组连续状态纹理；
- Balanced 模式固定 `256×256`、最高 `30 FPS`，使用双 FBO Ping-Pong；
- 状态纹理依次尝试 `RG16F`、`RGBA16F`、`RGBA8`；
- GPU 初始化异常时保留静态专辑渐变，不影响播放。

实现记录随 Git 源码保存于 `docs/图灵歌词原型.md`。

## 当前版本功能

- 保留 Amberol 本地播放、播放队列、波形、封面取色、MPRIS 和 GStreamer 后端。
- 原生 Rust + GTK4 + libadwaita 实现，不使用 WebView。
- 毛玻璃歌词卡片、左侧整体模糊和 GPU 图灵反应扩散动态背景。
- 同名 LRC 自动加载与逐句同步。
- 同名 TXT 后备。
- 歌词和队列互斥。
- 独立桌面入口、应用 ID、资源目录、翻译域和可执行文件名。

## 版本管理

源码使用 Git 管理；本次桌面应用与反应扩散背景作为独立里程碑提交。后续修改应先检查 `git status`，完成编译和测试后再提交。
