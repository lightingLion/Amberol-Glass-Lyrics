# Amberol Glass Lyrics 桌面应用使用说明

## 安装状态

应用已安装到本机，可在 GNOME 应用菜单搜索 **Amberol Glass Lyrics**。

也可从终端启动：

```bash
amberol-glass-lyrics
```

独立应用 ID：`io.github.amberolglass.Lyrics`。

## 歌词使用

1. 把 `.lrc` 歌词放在歌曲同一目录。
2. 歌词文件名需要与歌曲文件名相同。

示例：

```text
Glass in the Rain.flac
Glass in the Rain.lrc
```

支持标准时间标签、多个时间标签和 `[offset:+/-毫秒]`：

```lrc
[offset:-200]
[00:01.20]第一句歌词
[00:05.40]第二句歌词
```

同名 `.txt` 可作为纯文本歌词后备。

## 操作

- 右上角歌词按钮：展开或收起歌词卡片。
- `Ctrl+L`：切换歌词面板。
- `Esc`：关闭歌词面板。
- 点击左侧模糊区域：关闭歌词面板。
- 打开歌词时播放队列会自动收起；打开播放队列时歌词会自动收起。

## 窗口稳定性

歌词展开前会锁定左侧播放器的实际分配宽度，再请求顶层窗口扩展；歌词区域显示和窗口收缩也采用分阶段处理。因此专辑封面、波形、标题和播放控件不会在延伸瞬间重新排版或横向跳动。

## 图灵纹斑手书歌词

歌词卡片现在使用“前奏铺纹、稳定底图、歌词空腔、局部回填”的状态机：

- 参考 `arthurdouillard/turing_pattern_generator`，在 GPU 上执行20次半径2的模糊与300%锐化；
- 第一行 LRC 的时间戳决定前奏铺纹时长；
- 前奏结束后冻结全局纹斑，不再持续改变整体结构；
- Pango/Cairo 只生成歌词空腔遮罩，可见文字由 Shader 在既有纹路上逐帧挖空；
- 每句末段反向执行噪声阈值，让原纹斑在歌词区域局部回填；
- 9 FPS 阶梯式边缘变化和轻微采样抖动形成手书感；
- 模拟纹理固定 `256×256`，密度按照参考视频调整；
- 整个过程不使用可见 GTK Label 叠加。

实现记录随 Git 源码保存于 `docs/图灵歌词原型.md` 和 `docs/反应扩散参考实现.md`。

## 当前版本功能

- 保留 Amberol 本地播放、播放队列、波形、封面取色、MPRIS 和 GStreamer 后端。
- 原生 Rust + GTK4 + libadwaita 实现，不使用 WebView。
- 毛玻璃歌词卡片、左侧整体模糊和 GPU 图灵纹斑手书歌词背景。
- 同名 LRC 自动加载与逐句同步。
- 同名 TXT 后备。
- 歌词和队列互斥。
- 独立桌面入口、应用 ID、资源目录、翻译域和可执行文件名。

## 版本管理

源码使用 Git 管理；本次桌面应用与反应扩散背景作为独立里程碑提交。后续修改应先检查 `git status`，完成编译和测试后再提交。
