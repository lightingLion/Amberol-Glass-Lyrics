## 三角形区域故障

原顶点 Shader 将三个顶点映射到 `(-1,-1)、(1,-1)、(-1,1)`，这是视口内的半屏三角形，所以动画仅覆盖卡片的一半。

修正后使用超大单三角形，并让 GPU 在完整视口中插值出 `0..1` UV。模拟和显示两个 Pass 共用该顶点 Shader，因此 FBO 与最终卡片现在都会完整覆盖。
