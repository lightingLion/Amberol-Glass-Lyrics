# 图灵纹斑与手书歌词实现记录

当前算法参考：

- Arthur Douillard, `turing_pattern_generator`
- https://github.com/arthurdouillard/turing_pattern_generator

参考 Notebook 的核心过程是对灰度图重复执行 20 次：

1. 半径 2 的 Box Blur；
2. 半径 2、强度 300% 的 Unsharp Mask。

本项目在原生 OpenGL 中独立实现等价的 GPU 过程：第一次 5×5 Box Blur 直接采样；第二次 Box Blur 合并为9×9三角卷积核；之后执行 `blur + 3 × (blur - twiceBlurred)`。状态通过两个 FBO Ping-Pong 保存。

## 播放状态机

1. **前奏铺纹**：根据第一句 LRC 的开始时间，把20次迭代分散在前奏内完成；同时用带噪声的波前让纹斑逐步铺满卡片。
2. **稳定底图**：前奏结束后停止全局纹斑迭代，拓扑保持稳定，仅保留约9 FPS、亚像素级的手绘抖动。
3. **歌词空腔**：Pango/Cairo 生成当前歌词遮罩；Display Shader 用离散噪声阈值在稳定纹路中逐帧挖出空腔。
4. **局部回填**：根据当前句与下一句之间的时长，在末段反向降低空腔阈值，原来被冻结的纹斑只在歌词局部重新显露。

歌词不再注入 Chemical B，也不会触发整个背景重新生长。

## 密度与画布

- 状态纹理：256×256；
- Box Blur 半径：2；
- Unsharp 强度：300%；
- 迭代总数：20；
- 显示刷新：最高30 FPS；
- 手书采样节奏：9 FPS；
- 全屏三角形：`(-1,-1)、(3,-1)、(-1,3)`。

上述组合与参考视频中的紧密迷宫纹路密度接近，同时保持桌面应用的功耗范围。
