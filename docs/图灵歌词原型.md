# 图灵歌词最小原型

## 当前结构

歌词主体由 `AmberolReactionDiffusionView`（`GtkGLArea`）绘制。Pango/Cairo 只负责把当前歌词离屏栅格化为单通道遮罩；隐藏的 `GtkLabel` 仅保留数据/布局兼容性，不参与可见歌词绘制。

GPU 管线：

1. 256×256 Gray-Scott 状态纹理 A/B；
2. 当前歌词 `textMask`；
3. 上一句歌词 `previousTextMask`；
4. simulation shader 注入 Chemical B、施加软约束并侵蚀旧遮罩；
5. display shader 使用“反应浓度 × 遮罩约束 + 化学边缘发光 + 专辑三色调色板”输出。

Display Shader 从不把 `textMask` 直接输出为纯色文字。

## 单句阶段

- 播种（0–0.22 秒）：只在字形内以噪声阈值注入离散 Chemical B 斑点。
- 生长（约 0.12–0.95 秒）：软约束逐渐增强，化学纹路沿字形聚合。
- 稳定：字形仍由 Chemical B 浓度和细胞边缘共同形成，内部保持运动。
- 换句侵蚀（约 0.05–1.45 秒）：上一句遮罩进入 previousTextMask，噪声阈值与负注入令旧笔画断裂并回到自由纹路。

## 位置与裁剪

Pango 先计算实际字形尺寸，再从中央、四个偏置安全区选择候选位置；选择时限制与上一句的重叠率。整张遮罩上传到 GPU，随机的是种子位置。歌词卡片开启 `overflow: hidden`，纹路不会越出圆角卡片。

## 性能与后备

- Balanced：256×256、最高 30 FPS、每帧一次迭代；
- 双 FBO Ping-Pong；
- 状态纹理依次尝试 RG16F、RGBA16F、RGBA8；
- Shader/GL 初始化异常时保留静态专辑渐变，播放逻辑不受影响。

## 第一阶段测试歌词

```lrc
[00:00.00]Around the world
[00:03.00]La la la la la
[00:06.00]And everybody's singing
[00:09.00]La la la la la
```

音频能量与节拍 uniform 已在模拟器接口中预留；真实频谱/RMS/Beat 分析属于后续播放器音频链路接入，不包含在本次单句文字种子最小原型提交中。
