# Gray-Scott 图灵歌词原型

## 视觉原则

- 开场由音频决定的随机小圆点真实生长为图灵迷宫，不使用成品图案遮罩；
- 初始化完成后才从歌曲开头播放，确保第一句进入前底纹已经完整；
- 底纹在整首歌中使用同一张连续的 U/V 状态纹理，不切换预制动画；
- 歌词是现有纹路中的化学空腔，不是文字图层、黑色遮罩或透明度动画；
- 字腔内部保持低 Chemical V，字形边界由周围青色纹斑自然勾勒；
- 字腔出现完成后保持到当前句演唱结束；到下一条 LRC 时间戳时才解除旧字腔约束，现有纹路从边缘自然向内部重新生长；
- 出现、保持、回填不阻塞 LRC 时间轴，新句始终按时间戳触发；
- 主纹路一直缓慢演化，但参数固定、采样坐标不抖动，避免整幅画面跳动。

## 状态机

```text
AudioSeed
  ↓
INITIALIZING
  3600 次 Gray-Scott 迭代，播放器暂停
  ↓ pattern-ready
FREE_PATTERN
  音频从 0 开始，背景持续低速演化
  ↓ LRC cue
EMERGE 0.30s
  字形区域 U→1、V→0，空腔由纹路中冒出
  ↓
HOLD
  保持化学约束直到当前句演唱结束
  ↓ 当前句结束或下一条 LRC cue
RELEASE 1.20–4.00s
  解除旧字腔约束，Gray-Scott 从边界向腔内自然生长
  ↓
FREE_PATTERN
  旧字形不再可辨，等待下一时间戳
```

当前配方来自 `ph-200711/Turing-Patterns-Music-Video-Generator` 的 hazy void 模式：`F=.0480`、`K=.0615`、最大约束 `.13`。显示颜色完全由反应扩散浓度和浓度边缘产生；深色、中间色和高光色由专辑封面的多种提取色混合生成。

## 歌词时间轴

GStreamer 每 20 ms 发布一次 `position-ms`。歌词索引、出现时刻和遮罩更新都使用毫秒，不再经过 UI 的整秒位置值。播放器进度条和 MPRIS 仍可使用独立的普通位置属性。

如果用户在初始化期间触发播放，窗口会记录该意图并暂时保持暂停；收到 `pattern-ready` 后先 seek 到开头再继续。因此预热耗时不会吞掉前奏或提前跨过歌词时间戳。

## 可见图层

- 毛玻璃卡片背景；
- Gray-Scott ReactionDiffusionCanvas；
- 歌名、关闭按钮等少量辅助 UI；
- 隐藏的无障碍歌词文本。

歌词主体没有 GtkLabel、Cairo 文字着色或 textMask 直接合成。

## 验收观察点

1. 初始化时能看到随机种子经过模拟铺开，而不是一块一块显示成品纹理；
2. 初始化完成前音乐保持在开头；
3. 歌词出现时先改变局部化学状态，青色边界随迷宫结构自然形成；
4. 字腔出现完成后即开始回填；
5. 回填过程保留分裂、连接和迷宫形态，不是纯色填充；
6. 新句按 LRC 时间戳触发，不依赖旧句是否完全消失；
7. 关闭模拟后没有额外文字层残留。
