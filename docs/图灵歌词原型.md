# 图灵纹斑手书歌词原型

## 视觉原则

- 前奏期间，图灵纹斑从局部波前逐渐铺满歌词卡片；
- 铺满后全局纹路停止演化，不发生大范围漂移；
- 歌词不是纹路重新聚合成文字，而是在现有纹路中逐帧冒出的空腔；
- 每句结束前，空腔以不规则边缘局部回填；
- 纹斑拓扑始终保持，歌词只影响其所在区域的显示；
- 动画使用低帧率分段阈值、轻微边缘抖动，形成手书逐帧绘制感。

## 时间来源

- 第一行 LRC 的时间戳决定前奏铺纹时长；
- 当前行与下一行的时间差决定空腔保持和回填时长；
- 每句前段约0.3～0.75秒挖出空腔；
- 每句最后约0.4～1.05秒回填；
- 普通歌词时段保持空腔清晰稳定。

## GPU 管线

```text
随机灰度 Seed
  -> 20次 Blur + Unsharp Ping-Pong（仅前奏）
  -> 冻结的 Turing Pattern
  -> Pango/Cairo 歌词遮罩
  -> 手书噪声阈值挖空/回填
  -> 专辑配色映射
```

隐藏的 GTK Label 只保留辅助数据，不参与可见歌词绘制。
